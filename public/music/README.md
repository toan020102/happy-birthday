# Thêm nhạc vào phòng

1. Chép file `.mp3`, `.ogg` hoặc `.wav` vào thư mục này.
2. Thêm một mục tương ứng vào `playlist.json`.
3. Tải lại website. Chủ phòng sẽ thấy bài mới trong bảng **Âm nhạc**.

Ví dụ:

```json
{
  "id": "ten-khong-trung",
  "title": "Tên bài hát",
  "artist": "Tên nghệ sĩ",
  "src": "/music/ten-file.mp3"
}
```

Chỉ sử dụng nhạc mà bạn có quyền chia sẻ.
